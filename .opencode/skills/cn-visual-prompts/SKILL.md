## 2. 绝对禁忌（红线，违反即返工）

- ❌ 尴尬低幼剧情：「男友视角」「偷拍」「恶作剧」「偷吃」「偷看他」等一律禁止。
- ❌ 机械摆拍词：「标准微笑」「手叉腰站立」「比耶」「凹造型」「摆 pose」「正对镜头尬笑」等动词性摆拍描述禁止。
- ❌ 结构违规：提示词内**禁止出现方括号 `[]`**、**圆括号 `()`** 与**加号 `+`**；不得分点列条目，必须是一整段连贯、可直接复制的自然语言长句。
- ❌ 低俗化描写：避免直接性暗示化表述，保持「自然、清新、甜美、真实」的网红博主质感。

## 3. 提示词写作骨架

每一条完整提示词 = **一段连贯中文长句**，按序织入以下 5 个要素（缺一不可）：

1. **构图景别**：全景 / 中景 / 半身 / 近景 / 特写 / 环境人像 / 自然抓拍感，一句话点明视角与景别。
2. **动态与神态**：松弛舒展的自然瞬间（非摆拍），搭配「甜美微笑、温柔注视、若有所思、慵懒放松、灵动俏皮」等网红博主神态词。
3. **穿搭细节**：网红流行色系 + 高级面料质感 + 时尚剪裁（见 §4 语汇库）。
4. **环境实景**：真实网红打卡场景或具网红气质的实景（见 §5 场景库）。
5. **光影与胶片质感**：柔光光线 + 镜头参数 + 网红胶片氛围（见 §6 摄影参数库）。

### 写作步骤

1. 读取用户需求：主题（写真集/博主系列/日常穿搭）、人物的神态基调（甜美/知性/清冷/御姐）、想用的场景。
2. 从语汇库挑选：颜色 + 面料 + 剪裁 + 妆容 + 场景 + 光线 + 镜头。
3. 织成一段单一连贯中文长句，保持「景 → 动态神态 → 穿搭 → 环境 → 光影」的叙事流，句子之间用逗号、分号自然衔接，不出现任何方括号、括号或加号。
4. 自检：无红线词、无括号加号、段落连贯、5 要素齐全。
