## 3. 提示词写作骨架

每一条完整提示词 = **一段连贯中文长句**，按序织入以下 5 个要素（缺一不可）：

1. **构图景别**：全景 / 中景 / 半身 / 近景 / 特写 / 环境人像 / 自然抓拍感，一句话点明视角与景别。
2. **动态与神态**：松弛舒展的自然瞬间（非摆拍），搭配「抱着冲浪板跑、赤脚踩进浪里、回头爽朗地笑、被阳光晃到眯眼、拨开被风吹乱的长发、安静望着海」等加州邻家神态词。
3. **穿搭细节**：加州色系 + 高级面料质感 + 美式休闲剪裁（见 §4 语汇库）。
4. **环境实景**：真实加州场景或具阳光海岸气质的实景（见 §5 场景库）。
5. **光影与胶片质感**：加州阳光 + 镜头参数 + 胶片氛围（见 §6 摄影参数库）。

### 写作步骤

1. 读取用户需求：主题（阳光写真 / 冲浪少女 / 海岸人像 / 加州梦系列）、人物的神态基调（灿烂/亲切/自由/慵懒）、想用的场景。
2. 从语汇库挑选：颜色 + 面料 + 剪裁 + 妆容 + 场景 + 光线 + 镜头。
3. 织成一段单一连贯中文长句，保持「景 → 动态神态 → 穿搭 → 环境 → 光影」的叙事流，句子之间用逗号、分号自然衔接，不出现任何方括号、括号或加号。
4. 自检：无红线词、无括号加号、段落连贯、5 要素齐全。

- 海岸主调：海水蓝、帕尔玛蓝、奶油白、米色、卡其

## 7. 输出范例（结构示范）
