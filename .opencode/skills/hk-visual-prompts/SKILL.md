# 港系视觉 · HK Visual Prompts

为港系高级时尚写真（Vogue 香港 / 经典写真集风格）生成可直接复制给 AI 生图模型的**中文自然语言提示词**。核心理念：**清透氧气感 + 高级时尚感 + 自然生命力 + 香港电影感**。拍摄不局限在香港，但风格以港系为根。

## 触发关键词

港系 / 港风 / 港姐写真 / 香港电影感 / Vogue 香港 / 港式复古 / 霓虹夜色 / 维港 / 唐楼 / 茶餐厅 / 天星小轮 / 叮叮车 / 石澳 / 南丫岛 / 港式穿搭 / 夏日写真集 / 氧气感写真

## 1. 风格定调（一切写作的底层语法）

| 维度 | 港系美学目标 |
|------|--------------|
| 气质 | 清冷微甜、自然松弛、Effortless |
| 气息 | 清透氧气感、阳光生命力、干净不油腻 |
| 叙事 | 电影感、留白、孤独而自洽、有故事但不煽情 |
| 构图 | 35mm 环境人像 / 85mm 大光圈浅景深人像 |
| 质感 | 胶片颗粒、低饱和褪色暖调、逆光高光、港片色调 |

## 2. 绝对禁忌（红线，违反即返工）

- ❌ 尴尬低幼剧情：「男友视角」「偷拍」「恶作剧」「偷吃」「偷看他」等一律禁止。
- ❌ 机械摆拍词：「标准微笑」「手叉腰站立」「比耶」「凹造型」「摆 pose」等动词性摆拍描述禁止。
- ❌ 结构违规：提示词内**禁止出现方括号 `[]`**、**圆括号 `()`** 与**加号 `+`**；不得分点列条目，必须是一整段连贯、可直接复制的自然语言长句。
- ❌ 低俗化港姐描写：避免直接性暗示化表述，保持「高级、清透、微甜」的杂志质感。

## 3. 提示词写作骨架

每一条完整提示词 = **一段连贯中文长句**，按序织入以下 5 个要素（缺一不可）：

1. **构图景别**：全景 / 中景 / 半身 / 近景 / 特写 / 环境人像 / 逆光剪影，一句话点明视角与景别。
2. **动态与神态**：松弛舒展的自然动作（非摆拍），搭配「清透、微甜、疏离、自洽、若有所思」等高级神态词。
3. **穿搭细节**：色彩搭配 + 高级面料质感 + 剪裁细节（见 §4 语汇库）。
4. **环境实景**：真实香港场景或具港系气质的实景（见 §5 场景库）。
5. **光影与胶片质感**：时刻光线 + 镜头参数 + 胶片氛围（见 §6 摄影参数库）。

### 写作步骤

1. 读取用户需求：主题（写真集/剧照/单品/夜间）、人物的神态基调（清冷/微甜/松弛/疏离）、想用的场景。
2. 从语汇库挑选：颜色 + 面料 + 剪裁 + 妆容 + 场景 + 光线 + 镜头。
3. 织成一段单一连贯中文长句，保持「景 → 动态神态 → 穿搭 → 环境 → 光影」的叙事流，句子之间用逗号、分号自然衔接，不出现任何方括号、括号或加号。
4. 自检：无红线词、无括号加号、段落连贯、5 要素齐全。

### 色彩氛围（港系偏「清冷带一点暖」）
- 冷暖明净系：奶油白、珍珠色、雾灰蓝、浅青、薄荷绿、水鸭绿、鼠尾草绿、浅杏、燕麦色、鹅黄
- 港式复古系：南洋蓝、墨绿、酒红、砖红、焦糖棕、深蓝、黑色、正红（点缀）
- 搭配原则：以 1 个大色块 + 1 个小点缀色为佳，避免三色以上堆叠

## 8. 输出规范

- 用用户的语言回复（中文需求→中文提示词）。
- 提示词本体为单一连贯中文段落，无编号列表、无括号、无加号。
- 可按需成套输出（如「夏日写真集 50 组」），编号仅用于用户查阅，每组内部仍是独立连贯段落。
- 若用户要用英文模型，可先给中文原文，再附一段英文翻译备用，但默认以中文为准。
- 提供时附上可直接复制的后处理说明（横竖构图 / 胶片画幅 等）供用户自选。
