# 韩系视觉 · KR Visual Prompts

为韩系流行影像（韩剧氛围感 / K-pop MTV 音乐影像 / 首尔都市胶片 / 韩系初恋氛围）生成可直接复制给 AI 生图模型的**中文自然语言提示词**。核心理念：**氛围感 + 精致 MZ 都市感 + 韩剧心动的眼泪感 + 时态优雅冷静**。风格以韩系为根，但拍摄不局限于韩国。

韩系 / 韩剧 / 韩剧氛围感 / K-pop / Kpop / MTV / 韩系写真 / 首尔 / 汉江 / 弘大 / 梨泰院 / 圣水洞 / 韩系穿搭 / 韩系妆容 / 氛围感人像 / 灿烂一笑 / 阴雨天玻璃窗 / 心动的眼泪感 / 首尔都市胶片 / 韩系初恋

## 2. 绝对禁忌（红线，违反即返工）

- ❌ 尴尬低幼剧情：「男友视角」「偷拍」「恶作剧」「偷吃」「偷看他」等一律禁止。
- ❌ 机械摆拍词：「标准微笑」「手叉腰站立」「比耶」「凹造型」「摆 pose」「正对镜头尬笑」等动词性摆拍描述禁止。
- ❌ 结构违规：提示词内**禁止出现方括号 `[]`**、**圆括号 `()`** 与**加号 `+`**；不得分点列条目，必须是一整段连贯、可直接复制的自然语言长句。
- ❌ 低俗化描写：避免直接性暗示化表述，保持「干净、克制、氛围感、时态优雅」的韩剧杂志质感，不油腻。

## 3. 提示词写作骨架

每一条完整提示词 = **一段连贯中文长句**，按序织入以下 5 个要素（缺一不可）：

1. **构图景别**：全景 / 中景 / 半身 / 近景 / 特写 / 环境人像 / 前景介質构图 / 站立单人镜，一句话点明视角与景别。
2. **动态与神态**：松弛生动的自然瞬间（非摆拍），搭配「目光躲闪、嘴唇微张像要说什么、睫毛挂着碎光、侧头看过来、若有所思的浅笑」等韩剧式神态词。
3. **穿搭细节**：韩系色系 + 高级面料质感 + MZ 潮流剪裁（见 §4 语汇库）。
4. **环境实景**：真实韩系场景或具韩系气质的实景（见 §5 场景库）。
5. **光影与胶片质感**：韩剧氛围光 + 镜头参数 + 胶片氛围（见 §6 摄影参数库）。

### 写作步骤

1. 读取用户需求：主题（韩剧剧照 / K-pop 专辑 / 首尔街头写真 / 氛围感自拍）、人物的神态基调（冷静/心动/疏离/灿烂）、想用的场景。
2. 从语汇库挑选：颜色 + 面料 + 剪裁 + 妆容 + 场景 + 光线 + 镜头。
3. 织成一段单一连贯中文长句，保持「景 → 动态神态 → 穿搭 → 环境 → 光影」的叙事流，句子之间用逗号、分号自然衔接，不出现任何方括号、括号或加号。
4. 自检：无红线词、无括号加号、段落连贯、5 要素齐全。

## 4. 穿搭 / 妆容语汇库

### 面料质感（选 1–2 种叠加）
针织 / 羊毛混纺 / 灯芯绒 / 牛仔 / 皮革 / 缎面 / 雪纺 / 亚麻混纺 / 罗纹弹力 / 廓形棉

### 色彩氛围（韩系偏「奶咖 + 冷调 + 一点亮色」）
- 温柔主色：咖啡拿铁、燕麦奶、奶白、雾灰蓝、灰粉、深黑、燕麦色
- 小点缀色：樱花粉、柠檬黄、Tiffany 蓝、克莱因蓝、姨妈红、鹅黄
- 搭配原则：以 1 个大色块 + 1 个小点缀色为佳，韩系偏爱「低饱和色 + 一件亮色单品」的对比，整体偏奶咖与冷调。

### 剪裁与单品
| 单品 | 描述词 |
|------|--------|
| 上衣 | 高领针织、oversize 卫衣、廓形西装外套、法式娃娃领衬衫、露肩针织 |
| 下装 | 高腰直筒牛仔裤、百褶短裙、皮革半裙、阔腿西装裤、短裙配长袜 |
| 外套 | 宽松羊毛大衣、短款皮夹克、牛仔外套、风衣、针织开衫 |
| 鞋履 | 白色运动鞋、乐福鞋、玛丽珍鞋、袜套 + 平底鞋、厚底靴 |
| 点睛 | 细银链、珍珠耳环、冷调金属链、oversize 棒球帽、发夹、单肩包 |

### 妆容（韩系「水光肌 + 时态感」）
水光肌底妆 / 无粉感 / 玫瑰冷调眼影淡淡晕开 / 眼线微微上挑 / 水润唇釉 / 眉毛自然 / 腮红从颧骨轻扫到眼下 / 自然黑长直或羊毛卷，常有风把发丝吹起，眉目间带一点清冷的疏离

## 5. 场景库（实景 = 韩系灵魂）

- **首尔都市日常**：汉江公园的野餐垫、弘大的霓虹街头、圣水洞的工业风咖啡馆、梨泰院的巷弄、延南洞的奶油色小店、光化门的落叶大道
- **情感与氛围**：雨天的玻璃窗、夕阳余光洒进地铁车厢、深夜的路灯下、便利店暖光、屋顶天台看城市的灯火、旧书店里的留白
- **K-pop 舞台感**：摄影棚的逆光聚光灯、舞台背后的剪影、练习室的落地镜、专辑封面的纯色背景、升降机上的光
- **光线时刻**：阴天柔光、逆光毛边、霓虹与月光交织、车窗掠过灯影、黄昏最后一缕光

## 7. 输出范例（结构示范）

> 三比四竖版半身人像，五十毫米柔焦定焦大光圈镜头，人物站在首尔圣水洞工业风咖啡馆的大玻璃窗前，雨后水珠沿着玻璃滑落，透过水痕的模糊间隙望向窗外，侧脸情绪安静，目光里带着一点点说不清的心动，像把一场还没开始的告白藏进了雨里；她穿着一件燕麦奶色的高领细针织上衣，外搭一件灰蓝色廓形羊毛大衣，下身是一条高腰直筒牛仔裤，脚踩白色运动鞋，颈间一条细细的银色锁骨链在逆光下闪光；水光肌底妆清透，玫瑰冷调眼影淡淡晕在眼尾，水润唇釉微微反光，羊毛卷长发被晚风轻轻拂起几缕落在颊边，眉目间带着清冷的疏离与克制的温柔；背景是咖啡馆的模糊暖灯、窗外首尔街头的湿漉漉路面与霓虹倒影，前景玻璃上的雨珠被柔化成奶油色光斑；整体为韩式柔冷青调低饱和胶片质感，画面带一层薄薄的赛璐璐光泽与轻微颗粒，高光微微留白，黄昏最后一缕光把咖啡馆的暖意与首尔的冷调缝在一起，定格在一场没说出口的心动里。

## 8. 输出规范

- 用用户的语言回复（中文需求→中文提示词）。
- 提示词本体为单一连贯中文段落，无编号列表、无括号、无加号。
- 可按需成套输出（如「韩剧剧照 50 组」），编号仅用于用户查阅，每组内部仍是独立连贯段落。
- 若用户要用英文模型，可先给中文原文，再附一段英文翻译备用，但默认以中文为准。
- 提供时附上可直接复制的后处理说明（横竖构图 / 胶片画幅 / 胶片型号 等）供用户自选。
