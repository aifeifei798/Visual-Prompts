## 2. 绝对禁忌（红线，违反即返工）

- ❌ 尴尬低幼剧情：「男友视角」「偷拍」「恶作剧」「偷吃」「偷看他」等一律禁止。
- ❌ 机械摆拍词：「标准微笑」「手叉腰站立」「比耶」「凹造型」「摆 pose」「正对镜头尬笑」等动词性摆拍描述禁止。
- ❌ 结构违规：提示词内**禁止出现方括号 `[]`**、**圆括号 `()`** 与**加号 `+`**；不得分点列条目，必须是一整段连贯、可直接复制的自然语言长句。
- ❌ 低俗化描写：保持「含蓄、克制、典雅、有腔调」的英伦质感，不油腻、不做作、不刻意性感、不浮夸张扬。

## 3. 提示词写作骨架

每一条完整提示词 = **一段连贯中文长句**，按序织入以下 5 个要素（缺一不可）：

1. **构图景别**：全景 / 中景 / 半身 / 近景 / 特写 / 环境人像 / 克制抓拍感，一句话点明视角与景别。
2. **动态与神态**：松弛从容的自然瞬间（非摆拍），搭配「穿过回廊时的低头、被冷风吹起衣角、侧过头去看远处、安静地望着窗外、抱紧怀里的大衣领口、微微垂眸」等英伦从容神态词。
3. **穿搭细节**：英伦色系 + 高级面料质感 + 贵气学院剪裁（见 §4 语汇库）。
4. **环境实景**：真实英伦场景或具英伦气质的实景（见 §5 场景库）。
5. **光影与胶片质感**：英伦天光 + 镜头参数 + 胶片氛围（见 §6 摄影参数库）。

### 写作步骤

1. 读取用户需求：主题（英伦写真 / 学院风 / 雾都街拍 / 复古英伦大片 / 杂志编辑感）、人物的神态基调（克制/疏离/贵气/从容）、想用的场景。
2. 从语汇库挑选：颜色 + 面料 + 剪裁 + 妆容 + 场景 + 光线 + 镜头。
3. 织成一段单一连贯中文长句，保持「景 → 动态神态 → 穿搭 → 环境 → 光影」的叙事流，句子之间用逗号、分号自然衔接，不出现任何方括号、括号或加号。
4. 自检：无红线词、无括号加号、段落连贯、5 要素齐全。

## 4. 穿搭 / 妆容语汇库

### 面料质感（选 1–2 种叠加）

### 色彩氛围（英伦偏「沉稳暗调」）
- 厚重主调：咖啡驼、燕麦米、藏蓝、墨绿、烟灰、焦糖、金棕
- 克制点缀：酒红、砖橘、奶油白、格纹的精巧多色交织
- 搭配原则：偏好「低饱和重质感 + 一件格纹或亮色点睛」的沉稳感，驼蓝墨绿为主旋律，弱高饱和而强调面料与剪裁的贵气，整体内敛有层次。
