# 纽约模特视觉 · NY Visual Prompts

为纽约都市模特风（NYC 美版时尚编辑大片 / 纽约时装周 street style / 美式街头随性 cool-girl / 下城 Y2K 锋芒）生成可直接复制给 AI 生图模型的**中文自然语言提示词**。核心理念：**美式自信活力 + 街头随性 effortless + 编辑大刊的气场 + 纽约都市的多元与锋芒**。风格以美国纽约为根，但拍摄不局限于纽约。

## 2. 绝对禁忌（红线，违反即返工）

- ❌ 尴尬低幼剧情：「男友视角」「偷拍」「恶作剧」「偷吃」「偷看他」等一律禁止。
- ❌ 机械摆拍词：「标准微笑」「手叉腰站立」「比耶」「凹造型」「摆 pose」「正对镜头尬笑」等动词性摆拍描述禁止。
- ❌ 结构违规：提示词内**禁止出现方括号 `[]`**、**圆括号 `()`** 与**加号 `+`**；不得分点列条目，必须是一整段连贯、可直接复制的自然语言长句。
- ❌ 低俗化描写：保持「自信、真实、洒脱、有态度」的美式杂志质感，不油腻、不刻板、不做作。

## 3. 提示词写作骨架

每一条完整提示词 = **一段连贯中文长句**，按序织入以下 5 个要素（缺一不可）：

1. **构图景别**：全景 / 中景 / 半身 / 近景 / 特写 / 环境人像 / 动态抓拍感 / 斜侧机位，一句话点明视角与景别。
2. **动态与神态**：松弛洒脱的自然瞬间（非摆拍），搭配「大步走过街头、回头望来的笑意、阳光下挑眉、咬一下唇、随意拨发、气场全开的从容」等美式神态词。
3. **穿搭细节**：美式色系 + 高级面料质感 + NYC 潮流剪裁（见 §4 语汇库）。
4. **环境实景**：真实纽约场景或具美式气质的实景（见 §5 场景库）。
5. **光影与胶片质感**：纽约都市光 + 镜头参数 + 胶片氛围（见 §6 摄影参数库）。

### 写作步骤

1. 读取用户需求：主题（NYC 大片 / 时装周场外 / 街头潮人 / 都市写真）、人物的神态基调（自信/洒脱/慵懒/锋芒）、想用的场景。
2. 从语汇库挑选：颜色 + 面料 + 剪裁 + 妆容 + 场景 + 光线 + 镜头。
3. 织成一段单一连贯中文长句，保持「景 → 动态神态 → 穿搭 → 环境 → 光影」的叙事流，句子之间用逗号、分号自然衔接，不出现任何方括号、括号或加号。
4. 自检：无红线词、无括号加号、段落连贯、5 要素齐全。

## 4. 穿搭 / 妆容语汇库

### 面料质感（选 1–2 种叠加）
牛仔 / 皮革 / 羊毛混纺 / 廓形棉 / 针织 / 缎面 / 雪纺 / 灯芯绒 / 尼龙 / 垮垮的弹力

### 色彩氛围（美式偏「高饱和撞色 + 都市中性」）
- 都市中性：黑、白、灰、驼色、卡其、牛仔蓝
- 个性撞色：正红、克莱因蓝、柠檬黄、荧光绿、橙、豹纹/格纹
- 搭配原则：偏好「基础大色块 + 一件个性单品」的冲突感，牛仔、皮革、oversize 常见，整体偏低饱和中性底 + 亮色点睛。

### 剪裁与单品
| 单品 | 描述词 |
|------|--------|
| 上衣 | oversize 卫衣、T 恤、挺括白衬衫、露脐针织、皮夹克、廓形西装 |
| 下装 | 高腰直筒牛仔裤、破洞牛仔、工装裤、皮革短裙、阔腿西装裤 |
| 外套 | 宽松牛仔外套、皮夹克、风衣、羊毛大衣、棒球服、西装外套 |
| 鞋履 | 白色运动鞋、厚底靴、乐福鞋、帆布鞋、穆勒鞋 |
| 点睛 | 金色链条、oversize 太阳镜、棒球帽、亮色腋下包、多层项链、发带 |

### 妆容（美式「自信裸感 + 一点锋芒」）
自然哑光底妆 / 保留一点雀斑与真实肤质 / 裸色或豆沙色唇 / 眉形利落 / 眼线利落或烟熏一点 / 小麦色健康肤色 / 发型随性,直发、脏辫、卷发、低马尾或自然散发，常有风把发丝吹散、带一点不被驯服的野性

- **纽约地标街拍**：曼哈顿第五大道的马路人行横道、苏活区的砖墙与防火梯、布鲁克林大桥的步道、高线公园的空中走廊、中央公园的草地与林荫道、时代广场的霓虹、下东区的地下酒吧外

- **都市生活**：街角咖啡店的外带窗口、地铁口的风、天台的城市风、傍晚的霓虹、书店门口、夜店外的灯光
- **光线时刻**：正午的日光硬影、黄金时刻的暖光、霓虹与街灯交织、闪光灯直射的街头抓拍感、雨后湿润街面的反射

## 7. 输出范例（结构示范）

> 三比四竖版全景环境人像，五十毫米定焦大光圈镜头，人物走在纽约曼哈顿下城的苏活区街头，人行横道的一侧是红砖墙与黑色防火梯，另一侧是午后的阳光洒下的砖影，她大步走过斑马线、一手拨开被风吹到脸上的发丝、回头望向这边，神情自信洒脱、带着一点上扬的挑眉与无所畏惧的笑意，像赶去秀场的路上也懒得停下来；她穿着一件象牙白的 oversize 挺括 T 恤，下摆随意扎进一条高腰直筒破洞牛仔裤，外搭一件洗旧的宽松牛仔外套只披不穿，脚踩一双白色厚底运动鞋，颈间一条金色多层项链在光下闪烁，手腕戴一块亮面腕表；自然哑光底妆保留了一点雀斑与真实肤质，裸色豆沙唇，眼线利落，小麦色健康肤色，青黑直长发被纽约的风吹散、几缕落在肩头，带一点不被驯服的野性；背景是苏活区的红砖建筑、沿街店铺的遮阳棚与远处一抹天际线，午后的阳光在她脸上投下清晰的暖色调、在身后拉出长长的影子；整体为 Kodak Portra 400 高对比时装调，色彩真实饱和、暖黄与冷蓝交织，高光带一点日光感，画面有街头闪光灯的像素级的真实感，把纽约街头那种大方从容、洒脱不羁的 cool-girl 气场定格在一个大步向前的瞬间里。
