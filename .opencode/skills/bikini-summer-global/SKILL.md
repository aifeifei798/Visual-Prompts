## 2. 绝对禁忌（红线，违反即返工，与 7 大风格一致）

- ❌ 尴尬低幼剧情：「男友视角」「偷拍」「恶作剧」「偷吃」「偷看他」等一律禁止。

- ❌ 低俗化描写：避免直接性暗示化表述，保持干净、高级、自洽的杂志质感。

## 3. 提示词写作骨架（位置规则是 affiliated 修复重点）

每一条完整提示词 = **一段连贯中文长句**，按序织入以下 5 个要素，缺一不可：

1. **构图景别**：全景 / 中景 / 半身 / 近景 / 特写 / 环境人像 / 逆光剪影，一句话点明视角与景别。
2. **动态与神态**：松弛舒展的自然动作，搭配温柔、自洽、松弛、专注、若有所思等高级神态词。
3. **穿搭段，只写比基尼本身**：比基尼的颜色 + 款式 + 面料质感 + 剪裁细节，另加罩衫、配饰、妆发。可从 §4 语汇库挑选。
4. **实景段，只写地点与人物**：全球真实海滩实景 + 模特的地域气质归属，如法国少女在尼斯、巴西少女在科帕卡巴纳。比基尼信息不得堆在这里，地点信息不得提前到穿搭段。
5. **光影与胶片质感**：时刻光线 + 镜头参数 + 胶片氛围，以主体风格的胶片为准，如 Kodak Portra 400 / Fujifilm Pro 400H。

### 写作步骤

1. 先定主体风格，再定全球模特归属与全球海滩。
2. 比基尼三件套在穿搭段一次交代清：颜色、款式、材质。
3. 地点与国籍在实景段一次交代清：哪片海、哪国少女、背景有什么。
4. 织成一段单一连贯中文长句，保持「景 → 动态神态 → 穿搭 → 环境 → 光影」的叙事流，逗号分号自然衔接，不出现任何方括号、括号或加号。
5. 自检：无红线词、无括号加号、段落连贯、5 要素齐全、比基尼与地点各就各位。
