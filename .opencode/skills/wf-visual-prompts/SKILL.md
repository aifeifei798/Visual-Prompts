# 武侠视觉 · WF Visual Prompts

为武侠电影风格写真（金庸 / 古龙 / 徐克武侠 / 港产武侠电影 / 江湖古装）生成可直接复制给 AI 生图模型的**中文自然语言提示词**。核心理念：**侠气纵横 + 山野清风 + 诗意江湖 + 武侠电影感**。拍摄不局限于实地，但风格以武侠电影为根。

武侠 / 武侠电影 / 金庸 / 古龙 / 徐克武侠 / 港产武侠 / 侠客 / 侠女 / 江湖剧照 / 武侠写真 / 古装武侠 / 剑气 / 山野 / 竹林 / 古城墙 / 青石板路 / 瀑布山巅 / 客栈 / 武侠胶片 / 侠义 / 恩怨情仇

## 2. 绝对禁忌（红线，违反即返工）

- ❌ 尴尬低幼剧情：「男友视角」「偷拍」「恶作剧」「偷吃」「偷看他」等一律禁止。
- ❌ 机械摆拍词：「标准微笑」「手叉腰站立」「比耶」「凹造型」「摆 pose」等动词性摆拍描述禁止。
- ❌ 结构违规：提示词内**禁止出现方括号 `[]`**、**圆括号 `()`** 与**加号 `+`**；不得分点列条目，必须是一整段连贯、可直接复制的自然语言长句。
- ❌ 低俗化武侠描写：避免直接性暗示化表述，保持「孤傲、凌厉、诗意、侠义」的江湖质感。

## 3. 提示词写作骨架

每一条完整提示词 = **一段连贯中文长句**，按序织入以下 5 个要素（缺一不可）：

1. **构图景别**：大远景 / 全景 / 中景 / 半身 / 近景 / 环境人像 / 逆光剪影，一句话点明视角与景别。
2. **动态与神态**：武侠动作或静止侠姿（非摆拍），搭配「孤傲、凌厉、侠气、诗意、疏离、若有所思」等高级神态词。
3. **穿搭细节**：古装武侠服饰 + 面料质感 + 兵器/配饰细节（见 §4 语汇库）。
4. **环境实景**：真实武侠场景或具武侠气质的实景（见 §5 场景库）。
5. **光影与胶片质感**：时刻光线 + 镜头参数 + 武侠胶片氛围（见 §6 摄影参数库）。

### 写作步骤

1. 读取用户需求：主题（武侠剧照/江湖写真/单品/夜间）、人物的神态基调（孤傲/凌厉/诗意/疏离）、想用的场景。
2. 从语汇库挑选：颜色 + 面料 + 剪裁 + 妆容 + 场景 + 光线 + 镜头。
3. 织成一段单一连贯中文长句，保持「景 → 动态神态 → 穿搭 → 环境 → 光影」的叙事流，句子之间用逗号、分号自然衔接，不出现任何方括号、括号或加号。
4. 自检：无红线词、无括号加号、段落连贯、5 要素齐全。

## 4. 穿搭 / 妆容语汇库

### 面料质感（选 1–2 种叠加）
绸缎 / 真丝 / 粗布麻纺 / 皮革 / 锦缎 / 刺绣棉麻 / 薄纱 / 羊毛呢 / 竹节棉

### 色彩氛围（武侠偏「青绿山水 + 烈色点缀」）
- 武侠主色：墨绿、青灰、藏蓝、黛黑、赭石、鸦青、月白、靛蓝
- 烈色点缀：猩红、赤金、锈铜、霜白、鸦青
- 搭配原则：以 1 个大色块 + 1 个烈色小点缀为佳，避免三色以上堆叠，强调山水画意境

### 剪裁与单品
| 单品 | 描述词 |
|------|--------|
| 袍服 | 宽袖古装长袍、束腰披风、立领对襟袍、水袖侠袍、暗纹锦缎长衫 |
| 下装 | 高腰阔腿古装裤、马面裙、束脚工装裤、曳地长裙 |
| 鞋履 | 短靴、长靴、布鞋、草鞋、绣花鞋 |
| 兵器 | 长剑、短刀、竹杖、枪杆、扇、弓、箭囊 |
| 点睛 | 斗笠、面具、束发带、丝绸腰带、锦囊、玉佩、虎头扣、金属护腕 |

### 妆容（保持「侠气利落」）
苍白底妆 / 利落剑眉 / 锐利眼神 / 淡烟熏或清透裸妆 / 侠女可加额饰或珠花 / 自然乌发束起或披散

## 8. 输出规范

- 用用户的语言回复（中文需求→中文提示词）。
- 提示词本体为单一连贯中文段落，无编号列表、无括号、无加号。
- 可按需成套输出（如「金庸武侠剧照集 50 组」「古龙江湖写真 30 组」），编号仅用于用户查阅，每组内部仍是独立连贯段落。
- 若用户要用英文模型，可先给中文原文，再附一段英文翻译备用，但默认以中文为准。
- 提供时附上可直接复制的后处理说明（横竖构图 / 胶片画幅 / 胶片型号 等）供用户自选。
