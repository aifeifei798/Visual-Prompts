# 日系小清新 · JP Visual Prompts

## 2. 绝对禁忌（红线，违反即返工）

- ❌ 尴尬低幼剧情：「男友视角」「偷拍」「恶作剧」「偷吃」「偷看他」等一律禁止。
- ❌ 机械摆拍词：「标准微笑」「手叉腰站立」「比耶」「凹造型」「摆 pose」等动词性摆拍描述禁止。
- ❌ 结构违规：提示词内**禁止出现方括号 `[]`**、**圆括号 `()`** 与**加号 `+`**；不得分点列条目，必须是一整段连贯、可直接复制的自然语言长句。
- ❌ 低俗化日系描写：避免直接性暗示化表述，保持「温柔、干净、青涩、微甜」的初恋杂志质感。

## 3. 提示词写作骨架

每一条完整提示词 = **一段连贯中文长句**，按序织入以下 5 个要素（缺一不可）：

1. **构图景别**：全景 / 中景 / 半身 / 近景 / 特写 / 环境人像 / 逆光剪影，一句话点明视角与景别。
2. **动态与神态**：松弛舒展的自然动作（非摆拍），搭配「温柔青涩、微甜、疏离、自洽、若有所思、像在心里偷偷说着什么」等高级神态词。
3. **穿搭细节**：色彩搭配 + 高级面料质感 + 剪裁细节（见 §4 语汇库）。
4. **环境实景**：真实日系场景或具日系气质的实景（见 §5 场景库）。
5. **光影与胶片质感**：时刻光线 + 镜头参数 + 胶片氛围（见 §6 摄影参数库）。

### 写作步骤

1. 读取用户需求：主题（写真集/剧照/单品/夜间）、人物的神态基调（温柔/青涩/微甜/疏离）、想用的场景。
2. 从语汇库挑选：颜色 + 面料 + 剪裁 + 妆容 + 场景 + 光线 + 镜头。
3. 织成一段单一连贯中文长句，保持「景 → 动态神态 → 穿搭 → 环境 → 光影」的叙事流，句子之间用逗号、分号自然衔接，不出现任何方括号、括号或加号。
4. 自检：无红线词、无括号加号、段落连贯、5 要素齐全。
